Paham, maksud Anda adalah agar klien tidak bisa menebak-nebak nama link milik klien lain (menghindari celah keamanan yang disebut ID Enumeration atau tebak urutan angka seperti pesanan01, pesanan02, pesanan03).
Jika klien A nakal dan mengganti tulisan di link iframe mereka menjadi pesanan02, meskipun halamannya akan memunculkan Access Denied karena domainnya tidak cocok, mereka tetap tahu bahwa Anda sedang mengerjakan proyek lain dengan nama folder tersebut.
Untuk mengatasinya, kita tidak perlu sistem kode yang rumit. Solusi paling standar dan profesional di dunia industri adalah menggunakan UUID / GUID (Unique ID Acak) atau Hash Key sebagai nama foldernya.
------------------------------
## Solusi Terbaik: Pakai Kode Acak (UUID) Sebagai Nama Folder
Alih-alih memberi nama folder pesanan01, pesanan02, atau pesanan03, buatlah folder dengan deretan karakter acak yang mustahil ditebak.
## Contoh Perubahan Struktur Folder di GitHub:

└── models/
    ├── client-7x8a2b9w/          <-- Ganti nama folder pesanan01 jadi ini
    │   └── artist01.glb
    └── client-3m9v4k2p/          <-- Ganti nama folder pesanan02 jadi ini
        └── karakter_game.glb

## Contoh Perubahan di File config.js:
Anda tinggal mendaftarkan kode acak tersebut ke dalam daftar hak akses:

const ACCESS_CONTROL_LIST = {
    // Klien A
    "client-7x8a2b9w": "://patreon.com",
    
    // Klien B (Mustahil ditebak oleh Klien A)
    "client-3m9v4k2p": "://patreon.com",
    
    "test": "localhost" 
};

window.ACCESS_CONTROL_LIST = ACCESS_CONTROL_LIST;

## Contoh Link <iframe> yang Diberikan ke Klien A:

<iframe src="https://github.io" ...></iframe>

Dengan cara ini, jika Klien A mencoba mengganti ujung linknya menjadi ?folder=client-7x8a2b9w2 atau menebak angka lain, mereka hanya akan mendapatkan error karena kodenya diacak total secara unik.
------------------------------
## Cara Membuat Kode Acak Tersebut (Tanpa Aplikasi Tambahan)
Di sistem Linux Anda, Anda bisa membuat kode acak unik ini dengan sangat mudah lewat Terminal VS Code. Cukup ketik perintah ini untuk menghasilkan kode acak instan:

# Membuat teks acak unik 8 karakter
cat /dev/urandom | tr -dc 'a-zA-Z0-9' | fold -w 8 | head -n 1

(Setiap kali Anda menekan Enter pada perintah di atas, Terminal Linux akan memunculkan kombinasi kode acak baru yang unik untuk nama folder klien Anda).
Dengan metode nama folder acak (obfuscated folder name) ini, privasi antar klien Anda di dalam satu repositori TinoAjaDb01 dijamin aman 100% dan tidak bisa dirunut oleh siapapun.
Apakah Anda ingin saya bantu buatkan daftar kode acak siap pakai jika saat ini Anda sudah memiliki beberapa antrean proyek klien yang ingin didaftarkan?
